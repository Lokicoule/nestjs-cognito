# WebSocket

`@Authentication()` and `@Authorization()` work on socket.io gateways. The token is verified on every message, so a token that expires during a long-lived connection is rejected from the next message on.

## Protect messages

```typescript
import {
  Authentication,
  Authorization,
  CognitoUser,
  CognitoWsExceptionFilter,
} from '@nestjs-cognito/auth';
import { UseFilters } from '@nestjs/common';
import { SubscribeMessage, WebSocketGateway } from '@nestjs/websockets';

@WebSocketGateway()
@UseFilters(CognitoWsExceptionFilter)
export class MessagesGateway {
  @SubscribeMessage('messages')
  @Authentication()
  findAll(@CognitoUser('username') username: string) {
    return { username };
  }

  @SubscribeMessage('moderate')
  @Authorization(['moderator'])
  moderate() {
    return { ok: true };
  }
}
```

`CognitoWsExceptionFilter` sends authentication errors to the client as an `exception` event, with the same body as an HTTP response: `{ statusCode: 401, message, error }`. Without it, Nest reports them as `Internal server error`.

## Send the token

Browsers can't set headers on a WebSocket connection. Pass the token in `auth`:

```typescript
const socket = io('https://api.example.com', { auth: { token: accessToken } });
```

Node.js clients can also send `extraHeaders: { authorization: 'Bearer <token>' }`.

## Reject connections without a valid token

The guard protects each message. To close a connection as soon as it opens, add a socket.io middleware that reuses the module's verifier and extractor:

```typescript
import {
  CognitoJwtExtractor,
  CognitoJwtVerifier,
  InjectCognitoJwtExtractor,
  InjectCognitoJwtVerifier,
} from '@nestjs-cognito/core';
import { OnGatewayInit, WebSocketGateway } from '@nestjs/websockets';
import { Server } from 'socket.io';

@WebSocketGateway()
export class MessagesGateway implements OnGatewayInit {
  constructor(
    @InjectCognitoJwtVerifier() private readonly verifier: CognitoJwtVerifier,
    @InjectCognitoJwtExtractor() private readonly extractor: CognitoJwtExtractor,
  ) {}

  afterInit(server: Server) {
    server.use(async (socket, next) => {
      try {
        await this.verifier.verify(this.extractor.getAuthorizationToken(socket) ?? '');
        next();
      } catch {
        next(new Error('Unauthorized'));
      }
    });
  }
}
```

## From cookies

Sockets have no parsed cookies. Read them from the handshake with a custom extractor:

```typescript
import { CognitoJwtExtractor, parseCookies } from '@nestjs-cognito/core';
import { Socket } from 'socket.io';

export class SocketCookieExtractor implements CognitoJwtExtractor<Socket> {
  hasAuthenticationInfo(socket: Socket): boolean {
    return Boolean(this.getAuthorizationToken(socket));
  }

  getAuthorizationToken(socket: Socket): string | null {
    return parseCookies(socket.handshake.headers.cookie)['access_token'] ?? null;
  }
}
```

## Plain `ws`

The `ws` adapter (`@nestjs/platform-ws`) is not supported: its clients carry no headers after the connection is established. Use socket.io.
